# Secure Chat Application

A privacy-first messaging app where only the sender and receiver can read messages.
Messages are encrypted on the client before they leave the device, so the server never
sees plaintext.

## Features
- End-to-end encrypted messaging
- Secure user authentication
- Scam and phishing message detection
- React-based responsive chat interface
- Python (Flask/Django) REST backend

## Tech Stack
Python · Flask/Django · React · [database] · [crypto library]

## Getting Started
1. Clone the repo: `git clone https://github.com/i-poorvi17/<repo-name>.git`
2. Backend: `cd backend && pip install -r requirements.txt && python app.py`
3. Frontend: `cd frontend && npm install && npm start`
